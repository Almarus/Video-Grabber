# Video-Grabber
<img width="482" height="352" alt="изображение" src="https://github.com/user-attachments/assets/b0a33a8d-da83-4f68-b9eb-4de9db9b8925" />

Video Grabber - бесплатная программа для скачивания видео, плейлистов и каналов с популярных видохостингов и веб-сайтов

![Version](https://img.shields.io/badge/version-1.0-blue)
![Platform](https://img.shields.io/badge/platform-Windows-0078D4)
![Python](https://img.shields.io/badge/python-3.8+-3776AB)

---

## ✨ Основные возможности

| Функция | Описание |
|---------|----------|
| 🎥 **Загрузка видео** | Поддержка 1800+ сайтов: YouTube, VK, Rutube, Bilibili, Twitch и другие |
| 📋 **Плейлисты и каналы** | Скачивание целых плейлистов и каналов одним нажатием |
| 🎵 **Аудио режим** | Извлечение и сохранение аудио в формате MP3 |
| 📁 **Выбор качества** | Доступные форматы: 360p, 480p, 720p, 1080p, "Лучшее" |
| 🖼️ **Превью видео** | Просмотр миниатюры и информации о видео перед загрузкой |
| ⏹️ **Остановка загрузки** | Возможность прервать загрузку в любой момент |
| 🚀 **Многопоточность** | Загрузка нескольких видео из плейлиста одновременно (до 3 потоков) |
| 🔄 **Автообновление** | Встроенный механизм обновления yt-dlp и FFmpeg |

## 🚀 Установка и запуск

### Способ 1: Готовый EXE-файл (рекомендуется)

1. Скачайте последнюю версию из раздела [Releases](https://github.com/almarus/VideoGrabber/releases)
2. Запустите `VideoGrabber.exe`
3. При первом запуске программа предложит скачать необходимые компоненты (yt-dlp и FFmpeg)
4. Вставьте ссылку, выберите желаемое качество и нажмите скачать
